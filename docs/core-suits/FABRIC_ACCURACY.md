# Fabric Accuracy — 生地の再現度

## 正直に言うこと

**実物の色・質感・光沢を完全に再現することは保証できない。** 生成 AI の出力であり、撮影時の照明・カメラ・お客様の画面の色設定がすべて影響する。

だから、

- 生成画像には必ず「AI による完成イメージです。実物の色・質感とは異なる場合があります。最終確認は必ず生地の現物でお願いします。」を添える（スタジオ・顧客ページ・共有ページの3か所すべて。`npm run check:fake-ai` が見張っている）
- そのうえで、**再現度を上げるためにできることは全部やる**。ここが CORE Suits と「写真にスーツを着せるだけの AI」の差になる。

## やっていること

### 1. 生地の実物写真を必ず渡す

文字プロンプトだけで生地を作らせない。「チャコールのヘリンボーン」と書くだけでは、AI は毎回違う色・違う柄の大きさを作る。

生地写真を渡せない生地では `usedFabricReference = false` を記録し、**画面に赤字で「生地画像なし」と出す**。黙って作らない。

### 2. 画像を言葉より優先させる

台帳の色名・混率・目付・光沢も渡すが、指示書に明記している。

> The IMAGE takes priority over these words.

言葉が画像と食い違ったとき、画像を勝たせる。

### 3. 柄の大きさを指定する

スウォッチのマクロ写真をそのまま解釈すると、ジャケット上で柄が巨大になる。

> Render the weave at realistic garment scale (a swatch photographed close up must not become an oversized pattern on the jacket).

### 4. 撮り方を揃えさせる

生地登録画面に、撮影条件のチェックリストと「この条件で撮影した」チェックを置いている（`fabric_images.capture_ok` に残る）。

- 同じ照明（自然光か、いつも同じ電球）
- 同じ距離・真上から・生地で画面いっぱい
- 影とテカリを入れない

条件が揃うほど再現度が上がるので、**UI がそれを促す**。

## 実測（2026-09-08）

同じ人物写真に、4種類の生地で生成した結果。

| 生地 | 色の一致 | 柄の一致 | 柄の大きさ | 人物の同一性 |
|---|---|---|---|---|
| チャコール ヘリンボーン | ◎ | ◎ | ◎ | ◎ |
| ダークブラウン ソリッド | ◎ | ◎（微細な織り目まで） | ◎ | ◎ |
| ネイビー ピンストライプ | ◎ | ○（ストライプ間隔がやや広い） | ○ | ◎ |

人物の同一性（顔・髪型・骨格・肌の色・姿勢・背景・光）は4回すべて維持された。

## 限界（正直に）

1. **細かい柄の間隔は完全には一致しない。** ピンストライプ・シャドーストライプは間隔がずれることがある
2. **光沢の再現が弱い。** モヘア混の強い光沢は再現しきれない
3. **画面の色は保証できない。** お客様のスマホの色設定次第
4. **色の再現は撮影条件に強く依存する。** 生地写真が黄色い電球下なら、生成物も黄色く寄る

## 今後（優先順）

1. **色補正**（Phase 2）… グレーカードや基準色票を一緒に写して、生地写真の色を機械的に揃える。撮影条件のばらつきを吸収する
2. **テクスチャ抽出**（Phase 3）… スウォッチから織り目のパターンを取り出し、タイル化してから合成する。柄の大きさのズレを構造的に潰す
3. **生地の自動認識**（Phase 4）… 生地帳を撮るだけで色・柄・系統を自動判定し、登録の手間を減らす

いずれも `ImageProvider` の内側の話なので、画面と API を変えずに差し替えられる。
